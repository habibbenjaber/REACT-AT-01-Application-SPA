1.. Étape 1 : Initialisation
Mise en place de la structure de base de l’application SPA, comprenant les fichiers essentiels : index.html, style.css et app.js.

L’application est développée en cinq étapes. À chaque étape correspond une branche Git nommée etape-i, où i varie de 1 à 5.

Pour cloner les sources en local :
- Installer Git
- Ouvrir un terminal et exécuter la commande suivante :
     git clone https://github.com/habibbenjaber/REACT-AT-01-Application-SPA
- Pour basculer entre les différentes étapes, utiliser la commande :
     git checkout etape-i (avec i compris entre 1 et 5)

Si vous n’êtes pas familiarisé avec Git, vous pouvez télécharger les sources sous forme d’archive (ZIP) directement depuis GitHub.
